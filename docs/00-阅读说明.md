## 建议决定

采用 **Go + sllt/pi**，Runner 也先用 Go。不要同时做 Rust Runner、多控制节点、Agent 推理内核和通用工作流。首先实现一个真实 CLI 的单次执行—独立验收—取消恢复—导出闭环，再扩展三种 Agent 配置。
